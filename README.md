# PCB Gerber Quote Uploader

Simple WordPress plugin to collect customer PCB Gerber files and send quotation emails.

## Features

- Frontend shortcode form: `[pcb_quote_form]`
- Collects customer details (name, email, phone, company, project message)
- Accepts Gerber archive uploads in **ZIP** or **RAR** only
- Stores each request in WordPress Admin as **PCB Quote Requests**
- Admin can review customer details and download uploaded file
- Admin can send quotation email from request edit screen

## Installation

1. Copy this plugin folder into `wp-content/plugins/`.
2. Activate **PCB Gerber Quote Uploader**.
3. Add shortcode `[pcb_quote_form]` to a page.
4. Open **PCB Quote Requests** in WordPress admin to manage inquiries.
